# Além da Tática - Luiz Carlos dos Santos

E-book interativo hospedado no GitHub Pages.

## Como publicar:

1. Crie um repositório no GitHub chamado `alem-da-tatica`
2. Faça upload de todos os arquivos desta pasta (index.html e capa.webp)
3. Vá em Settings > Pages
4. Em Source, selecione `Deploy from a branch` e branch `main` / root
5. Salve. Seu link será: https://SEU-USUARIO.github.io/alem-da-tatica/

O arquivo index.html já é autossuficiente, não precisa de servidor.

## Estrutura:
- index.html = e-book completo
- capa.webp = capa em alta
